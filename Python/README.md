## 🚀 Getting Started

### Prerequisites

Ensure you have Python 3.8+ installed on your system.

```bash
python --version
```

### Running Scripts & Notebooks

You can run Python notebooks directly in VS Code, Jupyter Notebook, Jupyter Lab, or Google Colab:

```bash
# Launch Jupyter Notebook
jupyter notebook
```
