## 🚀 Getting Started

### Prerequisites

Ensure you have Python 3.8+ installed on your system.

```bash
python --version
```

### Running Scripts & Notebooks

You can run Python scripts directly or use Jupyter Notebook / Google Colab:

```bash
# Run a Python script
python script_name.py

# Launch Jupyter Notebook
jupyter notebook
```
