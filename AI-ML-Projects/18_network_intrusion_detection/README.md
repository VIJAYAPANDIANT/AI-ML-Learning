## 📌 Project Overview
Machine learning-driven cybersecurity system that analyzes network packet telemetry (packet size, connection duration, protocol type, error flags) to detect and classify cyber threats (DoS, Port Scans, Probe, Exploits) in real time.

## 🛠️ Tech Stack & Algorithms
- **Data Processing:** Pandas, Scikit-learn (NSL-KDD / CIC-IDS Benchmark schema)
- **Algorithms:** Random Forest Classifier, Multi-Class Logistic Regression, XGBoost
- **Metrics:** False Alarm Rate (FAR), Detection Rate, Precision-Recall Curve
