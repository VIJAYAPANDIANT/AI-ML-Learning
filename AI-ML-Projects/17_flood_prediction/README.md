## 📌 Project Overview
Predict municipal flood risks across urban watersheds using precipitation forecasts, catchment elevation, soil drainage capacity, and historical flood inundation levels.

## 🛠️ Tech Stack & Algorithms
- **Data:** Precipitation radar, Digital Elevation Models (DEM), River gauge sensors
- **Algorithms:** XGBoost / Gradient Boosting Classifier, Logistic Regression
- **Metrics:** Precision-Recall AUC, Brier Score, Inundation Risk Tiering
