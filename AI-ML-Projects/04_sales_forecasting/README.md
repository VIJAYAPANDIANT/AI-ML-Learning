## 📌 Project Overview
Forecast future weekly store revenues across retail categories using historical time-series signals, calendar seasonality, lag features, and gradient boosting.

## 🛠️ Tech Stack & Algorithms
- **Data Processing:** Pandas, NumPy
- **Feature Engineering:** Rolling 7-day/30-day means, Day-of-week & holiday flags, Autoregressive lag features
- **Algorithms:** Random Forest Regressor, Gradient Boosting Regressor
