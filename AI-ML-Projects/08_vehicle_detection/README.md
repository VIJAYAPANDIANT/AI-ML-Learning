## 📌 Project Overview
Computer vision surveillance system that detects, classifies, and tracks multi-class vehicles (Cars, Buses, Trucks, Motorcycles) in live traffic video feeds and computes real-time road congestion indices.

## 🛠️ Tech Stack & Algorithms
- **Computer Vision:** OpenCV, YOLO / Anchor-Based Object Detection
- **Tracking:** Centroid Tracking & Intersection Over Union (IOU)
- **Features:** Directional counting lines, Vehicle speed estimation, Congestion density scoring
