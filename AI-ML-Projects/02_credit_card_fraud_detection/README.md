## 📌 Project Overview
Detect fraudulent financial transactions in highly imbalanced datasets (e.g. 0.1% fraud rate). Evaluates Isolation Forest, Logistic Regression with class-weight rebalancing, and Precision-Recall tradeoffs.

## 🛠️ Tech Stack & Algorithms
- **Data Processing:** Pandas, NumPy
- **Algorithms:** Logistic Regression (Class-Balanced), Random Forest, Isolation Forest (Anomaly Detection)
- **Evaluation Metrics:** Precision, Recall, F1-Score, PR-AUC, Confusion Matrix
- **Techniques:** Cost-sensitive learning, Threshold optimization
