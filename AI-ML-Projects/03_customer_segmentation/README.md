## 📌 Project Overview
Segment e-commerce customers into actionable cohorts (High-Value Champions, Loyalists, At-Risk, Inactive) using Recency, Frequency, and Monetary (RFM) metrics.

## 🛠️ Tech Stack & Algorithms
- **Data Processing:** Pandas, NumPy
- **Unsupervised Learning:** K-Means Clustering, DBSCAN, PCA Dimensionality Reduction
- **Metrics:** Silhouette Score, Elbow Method ($WSS$)
