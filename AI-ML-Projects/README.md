Welcome to the **Real-World AI/ML Projects** portfolio module. This suite contains **18 complete, production-grade applications** solving real industry problems across Machine Learning, Deep Learning & Computer Vision, Generative AI & RAG, and Domain-Specific Enterprise/IoT systems.

Each project contains its own dedicated:
- 📖 **`README.md`**: Problem statement, dataset documentation, architecture, and evaluation metrics.
- 📓 **`notebook.ipynb`**: End-to-end executable Jupyter notebook with exploratory analysis, training, validation, and inference.
- 🐍 **`pipeline.py`**: Standalone production inference and pipeline script.
