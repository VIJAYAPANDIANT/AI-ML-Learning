## 📌 Project Overview
Conversational Data Analytics assistant: Upload CSV, Excel, or Parquet datasets and ask natural language questions. The assistant generates safe Pandas / SQL aggregation code, renders interactive charts, and produces executive narrative insights.

## 🛠️ Tech Stack & Algorithms
- **Data Engine:** Pandas 2.0+, DuckDB
- **Safety:** AST Python Code Sanitizer & Sandboxed Execution
- **Output:** Automated summary tables and executive bullet insights
