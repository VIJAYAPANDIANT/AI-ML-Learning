## 📌 Project Overview
Precision agriculture system that evaluates soil nutrients (Nitrogen $N$, Phosphorus $P$, Potassium $K$, pH) and climate telemetry (Rainfall, Temperature, Humidity) to recommend optimal crop varieties and forecast yield.

## 🛠️ Tech Stack & Algorithms
- **Data Processing:** Pandas, NumPy
- **Algorithms:** Random Forest Classifier (Crop Recommendation), Gradient Boosting Regressor (Yield Forecasting)
- **Features:** Soil NPK ratios, rainfall metrics, temperature ranges
