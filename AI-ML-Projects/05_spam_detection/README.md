## 📌 Project Overview
Classify suspicious emails, SMS messages, and phishing attempts using TF-IDF feature extraction, suspicious URL regex heuristics, and Naive Bayes / Logistic Regression.

## 🛠️ Tech Stack & Algorithms
- **NLP:** Scikit-learn TF-IDF Vectorizer, Regex keyword & URL extraction
- **Algorithms:** Multinomial Naive Bayes, Logistic Regression
- **Metrics:** Precision, Recall, Confusion Matrix, ROC-AUC
