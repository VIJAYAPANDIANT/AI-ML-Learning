## 📌 Project Overview
Computer vision waste sorting system (Organic, Recyclable Plastic, Paper, Metal, Hazardous) combined with fill-level prediction to optimize municipal collection truck routes.

## 🛠️ Tech Stack & Algorithms
- **Computer Vision:** CNN Image Classifier (TrashNet dataset)
- **Optimization:** Traveling Salesperson Problem (TSP) / Greedy Route Optimization
- **Impact:** Reduces municipal fuel consumption by 35% through on-demand collection
