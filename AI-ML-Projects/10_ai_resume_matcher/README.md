## 📌 Project Overview
Automated talent intelligence engine that parses resumes, extracts candidate competencies using structured schemas, computes semantic similarity against job descriptions, and identifies skill gaps.

## 🛠️ Tech Stack & Algorithms
- **Extraction:** Pydantic Schemas, Regular Expressions
- **Semantic Embeddings:** Sentence-BERT / Cosine Proximity
- **Analytics:** Jaccard Skill Overlap, Gap Analysis & Match Percentage
