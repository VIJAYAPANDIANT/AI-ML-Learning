## 📌 Project Overview
Industrial IoT intelligence system analyzing real-time vibration, vertical acceleration, and rail temperature telemetry from track sensors to detect structural track deformities, rail fractures, and corrugation anomalies.

## 🛠️ Tech Stack & Algorithms
- **Data Ingestion:** ESP32 / Industrial Accelerometer Telemetry
- **Algorithms:** Isolation Forest, Moving Z-Score Anomaly Detector, FFT Spectral Analysis
- **Serving:** FastAPI real-time alerting webhook
